# ProjectPlanner

A lightweight, browser-based project planner for mapping work, dependencies, and
the requirements and decisions each step needs.

## Run it

Open `index.html` in a modern browser. No build step or server is required. Your
project is saved in that browser's local storage.

## Plan a project

- Add steps with a duration, status, and any prerequisite steps.
- Record requirements or inputs to obtain, along with discussion points and risks.
- Use **Project timeline** to see the scheduled weeks and **Dependency map** to
  see which steps unlock others.
- Critical-path steps are highlighted in red. A delay to one of these steps can
  move the overall project finish.
- Edit or delete steps as the plan changes. Deleting a step removes it as a
  prerequisite from other steps.

The sample plan illustrates the visualizations and can be restored at any time
with **Reset sample plan**.
